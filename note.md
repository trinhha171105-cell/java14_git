# GITHUB

## DEMO GIT
- khoi tao du an github voi file note.md
- `git --version` : kiem tra phien ban
- `git config --global user.name "your_name"` yourname thi de gi cung duoc : cau hinh thong tin
- `git config --global user.email "your_github_email"` email phai la mail github
    - lenh global de cau hinh thong tin cho may chi lam 1 lan

- `git init`: khoi tao su dung git cho du an, moi du an lam mot lan
- `git remote add origin https://github.com/trinhha171105-cell/java14_git.git` : ket noi folder trong may voi repo online
- step1: 
    - `git add.` : them tat ca cac thay doi de day len github
    -`git add <ten_file>` la them mot file vao danh sach theo doi

- step2:
    - `git commit -m 'noi dung commit'` : chup man hinh code o thoi diem thao tac

- step3:
    - `git push -u origin <ten_branch>` : chay lan dau tien cua branch
    - `git push` : chay nhung lan con lai
